# Proyecto de Regresión Lineal

Este proyecto utiliza un conjunto de datos de seguros para aplicar técnicas de regresión lineal en el contexto de aprendizaje automático.

## Contexto de la Data

"Machine Learning with R" de Brett Lantz es un libro que proporciona una introducción al aprendizaje automático utilizando R. Según la información disponible, Packt Publishing no pone a disposición sus conjuntos de datos en línea a menos que compres el libro y crees una cuenta de usuario, lo cual puede ser un problema si estás consultando el libro de la biblioteca o lo has pedido prestado. Todos estos conjuntos de datos son de dominio público, pero necesitaban ser limpiados y recodificados para coincidir con el formato del libro.

## Fuente de los Datos

El conjunto de datos utilizado en este proyecto se puede encontrar en Kaggle:

[Insurance Dataset - Kaggle](https://www.kaggle.com/datasets/mirichoi0218/insurance?resource=download)

## Objetivo

El objetivo principal es aplicar y entender los conceptos de regresión lineal utilizando datos reales del sector de seguros.

## Pregunta de investigación

¿Qué regiones muestran costos mayores tras controlar por edad, BMI y número de hijos?
