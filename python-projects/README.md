## Projects

### 📦 EDA Library — [`eda-library/`](./eda-library/)
A Python package for automated Exploratory Data Analysis. Get a comprehensive dataset summary in a single function call.

```python
from libreria_eda import analyze_data
results = analyze_data(df)
```

**Features:** missing values, data types, memory usage, duplicate detection  
**Stack:** Python · Pandas · NumPy  
**Install:** `pip install -r requirements.txt`
