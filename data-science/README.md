## Projects

### 📊 F1 Historical Analysis
Exploratory data analysis on Formula 1 historical data covering circuits, drivers, constructors, standings, lap times, pit stops, and race results from multiple seasons.

**Key work:**
- Dataset integration across 14+ CSV files
- Missing values analysis and data cleaning
- Exploratory analysis with visual summaries

**Stack:** Python · Pandas · Jupyter Notebook

📁 [`eda.ipynb`](./eda.ipynb) · [`cleaning_data/`](./cleaning_data/)

---

**Dataset source:** [Ergast Motor Racing API](http://ergast.com/mrd/)
